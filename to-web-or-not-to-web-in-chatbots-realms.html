To web or not to web (in chatbots realms)?

March 2, 2017

Hi Matt,

As far as I understand, convos, maybe acronym for Conversational Objects :-), are chatbots applications (made by Octane AI) to be embedded inside a web site.

That’s interesting, and by the way, that’s the exact opposite of WeChat mini-programs paradigm (to embed a web application inside a chat messaging app).

Both approaches have in common the idea that the web paradigm (GUI web UX) will survive, coexisting with full conversational man-machine interactions (text-based and voice-based). I feel that’s true now in 2017, but things will probably change very soon.

The big question, in my modest opinion, is now:

Does the web way(HTML/CSS and mobile apps = GUI), and the chatbot technology on top, are the medium for some years now ? 
Or we are going very fast with a pervasive full conversational user interfaces (CUI/VUI) ?

I feel we are going, faster than we think in these days, towards #voicefirst chatbots.

This is not a bad news for us, bot-makers or conversational computing engineers, because all in all, the real point is not the interface but the substance (let me say, once a time) the intelligence, usefulness and creativity of a smart bot application. 
Machine learning is not the point, 
interface media is not the point; 
amazing conversational user experiences for great services, that’s the point.

my two cents
giorgio
